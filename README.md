# Awesome AI App Builders

A curated list of AI-powered tools for building apps, full-stack software, and internal tools from prompts.

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

AI app builders turn a text prompt, a spreadsheet, or a design into a working application. This list covers prompt-to-app generators, mobile app builders, no-code and low-code platforms with AI, internal-tool builders, AI coding agents and IDEs, and AI-assisted backend and database tools. Every entry is a real, publicly available product, described in a single neutral sentence. Listing is not an endorsement.

## Prompt-to-App / Full-Stack Builders

Tools that generate a complete frontend, backend, and data model from natural-language prompts.

- [AppWizzy](https://appwizzy.com/) — Generates and edits web apps from prompts and runtime templates in dedicated cloud development VMs, with Git-backed source editing.
- [Base44](https://base44.com) — No-code AI builder that generates full-stack web apps with frontend, database, auth, and hosting from chat; acquired by Wix in 2025.
- [Bolt.new](https://bolt.new) — In-browser AI builder running on StackBlitz WebContainers that generates and runs full-stack JavaScript and TypeScript apps with editable code.
- [Chef by Convex](https://chef.convex.dev) — Open-source AI builder that generates real-time full-stack apps on the Convex backend, including database, auth, file uploads, and jobs.
- [Create](https://www.create.xyz) — AI builder that turns text prompts into web and mobile apps with built-in auth, databases, and integrations, with code export.
- [Emergent](https://emergent.sh) — Multi-agent builder that generates full-stack apps with a React frontend, a Node.js or FastAPI backend, and MongoDB, syncing builds to a GitHub repo.
- [Famous.ai](https://famous.ai) — AI builder that generates production code for web and mobile apps with auth, payments, databases, and backend logic.
- [Hostinger Horizons](https://www.hostinger.com/horizons) — Chat-based no-code builder that generates web apps from prompts with integrated hosting, deployment, SSL, domains, and email.
- [Lazy AI](https://getlazy.ai) — Prompt-based builder for internal tools, APIs, and automations that generates frontend and backend web apps and deploys them to the cloud.
- [Lovable](https://lovable.dev) — AI builder that generates full-stack web apps from natural-language prompts, producing a React and TypeScript frontend with a backend, database, auth, and hosting.
- [Marblism](https://ai.marblism.com) — AI builder that generates full-stack web apps from prompts.
- [Mocha](https://getmocha.com) — AI builder that generates full-stack web apps with UI, backend, auth, database, and payments from text or images, with one-click publish and code export.
- [Playcode](https://playcode.io/ai-website-builder) — Prompt-to-production app builder where Playcode AI builds the interface, backend, and data model, then Playcode Cloud runs it with hosting, a database, and HTTPS.
- [Replit Agent](https://replit.com/products/agent) — AI agent inside the Replit cloud IDE that writes code, installs dependencies, provisions a database, and deploys apps from prompts.
- [Softgen](https://softgen.ai) — Conversational builder that generates full-stack Next.js apps with Firebase or Supabase, including auth, database, payments, and hosting.
- [Tempo](https://www.tempo.new) — AI builder that generates and edits React code in a real codebase with a visual drag-and-drop editor, GitHub push, and VS Code editing.
- [Trickle](https://trickle.so) — Agentic-canvas builder that generates websites, web apps, forms, and internal tools from prompts with a built-in database and serverless backend.
- [v0 by Vercel](https://v0.app) — Vercel's tool that generates Next.js, React, Tailwind, and shadcn/ui frontends and full-stack apps via a sandbox runtime.

## Mobile App Builders

Tools that generate native or cross-platform mobile apps with AI.

- [a0.dev](https://a0.dev) — AI builder that generates Expo and React Native projects for iOS and Android from chat prompts, with an in-browser simulator.
- [Adalo](https://adalo.com) — No-code visual builder for native iOS, Android, and web apps, with an AI assistant for prompt-based building.
- [Bilt](https://bilt.me) — AI builder that generates mobile apps from text or screenshot prompts and supports App Store submission.
- [CatDoes](https://catdoes.com) — Autonomous agent that generates React Native (Expo) apps plus Vite and Next.js websites with an included cloud backend and app-store submission.
- [Draftbit](https://draftbit.com) — Visual and AI builder that generates React Native (Expo) apps for iOS, Android, and web, with AI agents backed by major models.
- [FlutterFlow](https://flutterflow.io) — Visual builder that generates Flutter apps for iOS, Android, and web, with AI prompt-to-page, prompt-to-component, and image-to-component features.
- [magically](https://magically.life) — AI builder that generates full-stack React Native iOS and Android apps from a prompt, with auth, payments, and a Supabase database.
- [Newly](https://newly.app) — AI builder that generates React Native and Expo apps compiling to real native iOS and Android code, with a backend and source-code export.
- [OnSpace AI](https://www.onspace.ai) — AI builder that generates cross-platform mobile and web apps from natural-language prompts with GitHub and code export and a Supabase backend.
- [RapidNative](https://www.rapidnative.com) — AI builder that generates React Native and Expo screens for iOS, Android, and web from a prompt, with code export.
- [Rork](https://rork.com) — AI builder that generates production React Native (Expo) iOS and Android apps from prompts, with a top tier that generates native SwiftUI.
- [Superapp](https://www.superappp.com) — AI builder that generates native Swift iOS apps from plain-English descriptions, publishable to the App Store.
- [Thunkable](https://thunkable.com) — No-code platform that generates native iOS and Android apps, including an AI builder that generates apps from prompts.
- [Vibecode](https://www.vibecodeapp.com) — AI builder that generates mobile and web apps from prompts with on-device phone preview.

## No-Code / Low-Code App Builders with AI

Visual platforms that add AI generation on top of no-code or low-code building.

- [Airtable](https://www.airtable.com/platform/app-building) — Connected database and app platform whose AI builder generates apps with tables, automations, and interfaces from a prompt.
- [Bubble](https://bubble.io/ai) — No-code visual platform for web and mobile apps whose AI app generator turns a prompt into a working app with UI, database, and workflows.
- [Caspio](https://www.caspio.com) — Low-code platform for online database apps whose AI generates app components and reports from natural language.
- [Five.co](https://five.co) — Low-code rapid-application-development platform for business web apps with an AI generator that builds schema, tables, and forms from a prompt.
- [Flatlogic](https://flatlogic.com/generator) — AI web-app generator that builds full-stack apps with frontend, backend, database, auth, and roles from prompts and exports source to GitHub.
- [Glide](https://www.glideapps.com/ai) — Platform that turns spreadsheets and data sources into business apps, with AI that generates a custom app from a prompt or file.
- [Google AppSheet](https://about.google.com/appsheet) — No-code platform that builds apps from Sheets and databases, with Gemini generating apps from a description.
- [Knack](https://www.knack.com/ai-app-builder/) — No-code database-app platform whose AI builder generates the app foundation of tables, fields, roles, and pages from a text prompt.
- [Mendix](https://www.mendix.com/platform/ai/aiad/) — Enterprise low-code platform whose AI assistant generates domain models, pages, and microflows from conversational prompts.
- [Microsoft Power Apps](https://www.microsoft.com/power-platform/products/power-apps) — Low-code business-app platform whose Copilot builds apps and data models from natural-language descriptions.
- [Momen](https://momen.app) — Full-stack no-code web-app platform with a relational database, an AI copilot for database creation, and an AI agent builder.
- [Noodl](https://www.noodl.net) — Open-source visual node-graph low-code platform for full-stack web apps with AI assistance.
- [OutSystems](https://www.outsystems.com/generative-ai-app-builder/) — Enterprise low-code platform whose agent generates full applications from a prompt or requirements document.
- [Quickbase](https://www.quickbase.com/product/ai-capabilities) — Enterprise no-code platform whose AI app builder generates governed apps from plain-language prompts.
- [Softr](https://www.softr.io/ai-app-generator) — Platform that turns structured data into web apps and portals, with an AI co-builder that generates the interface, schema, auth, and permissions.
- [WeWeb](https://www.weweb.io/ai) — No-code and low-code builder for production web apps whose AI agent generates pages, database, and logic from natural language.
- [Zapier](https://zapier.com/agents) — Automation platform whose agents act across thousands of apps and whose Interfaces is an AI-assisted frontend and form builder.

## Internal Tool Builders with AI

Platforms focused on dashboards, admin panels, CRUD apps, and operational tooling.

- [Appsmith](https://www.appsmith.com) — Open-source low-code platform for internal apps with AI copilots that generate widgets and workflow logic from prompts.
- [Baserow](https://baserow.io) — Open-source no-code database and app builder with an AI assistant, AI fields, AI agents, and an MCP server.
- [Budibase](https://budibase.com) — Low-code platform for internal business tools with AI agents that integrate multiple model providers.
- [DronaHQ](https://www.dronahq.com) — Enterprise platform for internal apps and automations with agentic AI components and prompt-based generation.
- [Forest Admin](https://forest.app) — Operational backend and admin platform that connects databases and agents under an audited layer, supporting AI agents and an MCP server.
- [Jet Admin](https://www.jetadmin.io) — No-code platform for admin panels and portals with AI that generates apps, components, and custom agents from prompts.
- [NocoDB](https://nocodb.com) — Open-source no-code database that turns Postgres and MySQL into spreadsheet-style apps, with AI generating bases, tables, and fields.
- [Plasmic](https://www.plasmic.app) — Open-source visual builder for React apps that integrates with existing code, with AI that generates UI from text or image prompts.
- [Retool](https://retool.com) — Platform for internal tools connecting databases, APIs, and LLMs, with AI app generation that produces working apps from prompts.
- [Superblocks](https://www.superblocks.com) — Platform for governed enterprise apps with AI app generation and an agent that enforces governance rules.
- [ToolJet](https://www.tooljet.com) — Open-source platform for full-stack internal apps and workflows with an AI app builder that turns descriptions into apps and agents.
- [UI Bakery](https://uibakery.io) — Low-code platform for dashboards and CRUD apps with an AI agent that generates and deploys apps from chat.

## AI Coding Agents and IDEs

Agentic tools and editors that generate and modify application code.

- [Aider](https://aider.chat) — Open-source CLI AI pair-programming tool that edits files in a local git repo and auto-commits each change.
- [Anima](https://www.animaapp.com) — Figma-to-code tool and API that converts designs, prompts, or images into production HTML, React, Vue, and Tailwind code.
- [Augment Code](https://www.augmentcode.com) — AI coding platform for large multi-repo codebases with a deep context engine, an agent, and multi-agent orchestration.
- [Builder.io Visual Copilot](https://www.builder.io) — AI plugin and CLI that converts Figma designs into framework code and maps designs to existing repo components.
- [Claude Code](https://claude.com/product/claude-code) — Anthropic's agentic coding tool that reads a codebase, edits files, runs commands and tests, and handles git.
- [Cline](https://cline.bot) — Open-source autonomous coding agent for VS Code and JetBrains that edits files, runs commands, drives a headless browser, and supports MCP.
- [Continue](https://www.continue.dev) — Open-source AI coding assistant for VS Code and JetBrains with chat, autocomplete, and agent mode.
- [Cursor](https://cursor.com) — AI code editor with an agent that searches a codebase, edits files, runs commands, and completes multi-step tasks.
- [Devin](https://devin.ai) — Cognition's autonomous software-engineering agent that runs in a sandboxed cloud environment and produces pull requests.
- [GitHub Copilot](https://github.com/features/copilot) — AI assistant with an in-IDE agent mode and an asynchronous cloud coding agent that works from issues and opens pull requests.
- [Google Antigravity](https://antigravity.google) — Google's agentic development platform with an IDE, desktop client, Go CLI, and Python SDK.
- [Google Jules](https://jules.google) — Asynchronous Gemini-powered coding agent that runs tasks in a cloud VM and returns a finished pull request.
- [Kilo Code](https://kilo.ai) — Open-source AI coding agent for VS Code, JetBrains, and CLI that executes multi-step development tasks.
- [Kiro](https://kiro.dev) — AWS's agentic IDE centered on spec-driven development, turning prompts into executable specs.
- [Locofy](https://www.locofy.ai) — Design-to-code platform that converts Figma and design files into frontend code for React, Next.js, Vue, Flutter, and React Native.
- [OpenAI Codex](https://openai.com/codex) — AI coding agent across CLI, IDE, cloud, and desktop that writes features, fixes bugs, and proposes pull requests in cloud sandboxes.
- [OpenHands](https://www.openhands.dev) — Open-source, model-agnostic platform for cloud coding agents that automate engineering tasks.
- [Pazi](https://pazi.ai) — AI development platform using multiple specialized agents for full-stack web-app development.
- [Qodo](https://www.qodo.ai) — Agentic code-integrity platform for code generation, test generation, and automated pull-request review.
- [Subframe](https://www.subframe.com) — AI-native visual UI tool that outputs React and Tailwind components, with a CLI and MCP integration for coding agents.
- [Tabnine](https://www.tabnine.com) — AI code-completion and assistant platform with agents for review, testing, and refactoring, plus on-prem and air-gapped deployment.
- [Trae](https://www.trae.ai) — ByteDance's AI-native IDE with an agentic editor and an autonomous mode for multi-step builds.
- [Windsurf](https://windsurf.com) — AI-native IDE for managing local and cloud coding agents.
- [Zed](https://zed.dev) — Rust-based native code editor with an agent panel for agentic editing and support for external CLI agents via ACP and MCP.

## Backend / Database / API Builders with AI

Tools that generate or manage backends, databases, and APIs with AI.

- [Appwrite](https://appwrite.io) — Open-source backend with auth, databases, storage, functions, and messaging, plus MCP servers and AI database suggestions.
- [Backendless](https://backendless.com) — Visual backend-as-a-service with database, logic, auth, and hosting, whose AI generates a database schema from a text description.
- [Encore](https://encore.dev) — Open-source backend framework for TypeScript and Go that provisions cloud infra from code, with an MCP server giving AI agents schema visibility.
- [Hasura](https://hasura.io/promptql) — GraphQL engine over Postgres and other sources, centered on an AI data agent with a plan-execute-verify architecture.
- [Neon](https://neon.com) — Serverless Postgres platform whose SQL editor includes AI SQL generation, query naming, and a query-fixing assistant.
- [Nhost](https://nhost.io) — Open-source managed backend with Postgres, GraphQL, auth, and storage, plus an AI toolkit for embeddings, vector search, and assistants.
- [Supabase](https://supabase.com/features/ai-assistant) — Open-source Postgres backend whose AI assistant generates SQL, designs schemas, and creates row-level-security policies from natural language.
- [Wasp](https://usemage.ai) — Open-source full-stack framework whose free GPT-powered generator scaffolds a complete React, Node, and Prisma app.
- [Xano](https://www.xano.com/platform/build-with-ai/) — No-code Postgres backend whose AI agent generates backends from prompts and exposes a native MCP server for coding agents.
